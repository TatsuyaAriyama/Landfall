# Production provenance

- Character geometry: generated from Blender primitives and authored vertex lists in the KeelMira repository.
- Runtime source used for this package: `web/public/models/navigator.glb`.
- External texture files: none.
- Linked Blender libraries: none.
- Unity package dependencies: none outside UnityEngine.
- Third-party character models: none detected in the repository audit.

The packaged model is the rigged, lantern-equipped navigator that most closely matches the current procedural iOS character. The iOS character itself is generated at runtime, so small silhouette and cape-motion differences remain. KeelMira application code, Firebase code, user data, UI, logos and navigation systems are not included.
