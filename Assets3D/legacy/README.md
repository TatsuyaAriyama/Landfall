# Legacy navigator

These files preserve the procedural navigator that was replaced by the
Blender-authored Polaris Wayfinder in July 2026.

- `PhoenixModel.procedural.tsx.txt`: previous Three.js/Web implementation
- `PhoenixNavigator.procedural.swift.txt`: previous SceneKit/iOS implementation

They are deliberately stored as `.txt` snapshots so they remain available for
reference and recovery without being compiled into the current game.
