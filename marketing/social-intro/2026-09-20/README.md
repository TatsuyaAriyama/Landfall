# KeelMira 紹介ムービー

2026年9月20日に iPhone 17 Pro / iOS 26.5 Simulator 上で新規収録した実アプリ映像です。過去のスクリーンショット、生成したアプリ画面は使用していません。

## 完成ファイル

- `KeelMira-tiktok-40s.mp4` — 1080 × 1920、9:16、40秒、30 fps
- `KeelMira-x-40s.mp4` — 1080 × 1350、4:5、40秒、30 fps
- H.264 / AAC、字幕焼き込み、Web再生用faststart
- `captions.srt` — 字幕の編集用

## 構成

| 時間 | 映像 |
| --- | --- |
| 0–3秒 | 初期地点の桟橋 |
| 3–6秒 | 学習項目の一覧・読書を選択 |
| 6–14秒 | 出航のアニメーション |
| 14–20秒 | 海上での学習 |
| 20–25秒 | 学習完了の実画面 |
| 25–32秒 | 島への帰還 |
| 32–40秒 | ベンチに座って休む |

実際のアプリ操作は「学習完了 → ホームに戻る → 帰還」の順です。映像もその順序を維持しています。選択時の待ち時間と出航のみ短縮し、画面を捏造せずトリミングしています。

## 収録について

- シミュレータにインストール済みの署名付きDebugアプリを使用しました。新しいアプリの配布・本番更新は行っていません。
- 既存の `LANDFALL_SEED=1` によるメモリ内サンプル学習データを使い、実際に読書の航海を開始・完了しました。
- ベンチは既存の `LANDFALL_SEAT_DEMO=driftwood_bench` で実アプリの着席動作を呼び出しました。最後のカットはアプリのカメラモードをトリミングした映像です。
- BGM: アプリのオリジナル曲 `Landfall/Resources/harbor_minuet_main_theme.m4a`。作曲・生成元は `Tools/Audio/render_harbor_minuet.py`。
- `raw/` は今回の元収録、`work/` は編集用の中間ファイルです。大容量のためGit管理対象外です。
- 未使用の試し撮り（目標・カレンダー等）は完成版に含めていません。

## 再編集

`render_movie.py` がカット位置、速度、トリミング、字幕位置と書き出しを定義しています。PillowとFFmpegを使用します。`FFMPEG` 環境変数で実行ファイルを指定できます。

```sh
python3 render_movie.py --format both
```

フォントはmacOS標準のヒラギノ角ゴシックとAvenir Nextを使用しています。別OSで再編集するときはフォントパスを変更してください。
