# Navigator sticker set 01

航海士を、文字なしで日常会話に使える静止画スタンプ8種として再設計した初期セット。

## Set

1. 了解・任せて（敬礼）
2. ありがとう（胸に手を当てた軽いお辞儀）
3. あいさつ（大きく手を振る）
4. ごめんなさい（深いお辞儀）
5. 喜び・成功（両手を上げてジャンプ）
6. 応援・決意（拳と導きの灯）
7. しょんぼり（肩と灯りを落とす）
8. おやすみ（ケープにくるまって座る）

## Character lock

- 珊瑚色の尖ったフードとAラインのコート
- 深夜色の顔と、口を使わない2つの砂色の目
- 砂色の船綱、真鍮の8方位羅針盤、濃紺のケープ
- 焦茶の手袋とブーツ、小さい暖色のランタン
- 感情は目、頭の角度、肩、手、ランタンの位置で表現する

## Production

- Built-in image generation tool used with the existing navigator reference images.
- Chroma-key sources are preserved under `source/`.
- Transparent working images are preserved under `stickers/`.
- LINE-ready files are under `submission/`.
- Images contain no dialogue, letters, numbers, punctuation, speech balloons, or watermarks.
- AI use must be declared truthfully when submitting to LINE Creators Market.
