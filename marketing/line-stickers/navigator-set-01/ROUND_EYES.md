# Navigator Sticker Set — Round-Eye Edition

## Character invariant

Every gesture uses the same two ivory-white circular eyes. The eyes remain:

- perfectly round, never curved, closed, angled, or pupil-shaped
- equal in size and brightness
- separate and visually level inside the dark face opening

Emotion is communicated through pose, head angle, hands, cape, and lantern only.

## Eight wordless gestures

1. Salute / understood
2. Hand on compass / thanks
3. Wave / greeting
4. Deep bow / apology
5. Jump with both arms raised / joy
6. Fist and raised lantern / encouragement
7. Slumped posture / sadness
8. Curled seated rest / good night
